# SENSOR · 指尖接触力传感

本仓库保存指尖传感器的硬件资料，以及二代指尖的接触力标定与上位机实施方案。

## 从这里开始

| 文档 | 内容 | 适合什么时候阅读 |
|---|---|---|
| [二代指尖标定与上位机实施方案](docs/二代指尖标定与上位机实施方案.md) | 标定夹具、实验步骤、数据规范、页面布局、液泵控制、阶段交付与验收 | 规划实验与开发上位机 |
| [传感器硬件复现与接线说明](传感器硬件复现与接线说明.md) | 初代硬件供电、I2C、串口、ST-LINK 接线与验收 | 接线、烧录与基础读数检查 |

## 当前资料状态

- 二代传感器数量：**4 个**；目标：**接触力测量**。
- 已有资料：硬件接线说明、6 张硬件照片。
- 待补充：STM32 / ESP32 固件、原始串口数据、六维参考传感器协议、液泵控制与反馈资料。
- 本仓库目前没有可运行的上位机程序或已验证的标定模型。方案中的性能指标是设计与验收建议，不代表已测得的性能。

建议实施顺序：**设备与数据确认 → 法向力标定 → 实时显示和记录 → 手动液泵控制 → 力反馈闭环**。
